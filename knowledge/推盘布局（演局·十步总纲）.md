## 卡 01 ｜推盘布局（演局·十步总纲）

**核心概念**

「推盘布局其实很简单，一共分为以下十步。」

原文以表格呈现十步总纲，逐字照录：

| 步骤 | 内容 |
|---|---|
| 第一步 | 以二至定阴阳 |
| 第二步 | 以节气定局 |
| 第三步 | 以日干支定三元 |
| 第四步 | 排地盘 |
| 第五步 | 以时干支找旬首，地盘旬首定符使 |
| 第六步 | 从地乙（地盘旬首）宫起，排布暗干支 |
| 第七步 | 排天盘：值符加地盘时干上，星干同飞 |
| 第八步 | 排人盘：值使加时支上 |
| 第九步 | 排神盘　天盘九神【值符加天乙（天盘旬首）】　地盘九神【值符加地乙（地盘旬首）】 |
| 第十步 | 定空亡 |

**使用规则**：原文未提及

**操作步骤**：按上表第一至第十步依次进行。
